Stock Sector Tracker Map 소개 및 이용 안내
📌 서비스 소개
Stock Sector Tracker Map는 한국과 미국 주식시장의 섹터별 일일 등락률 흐름을 한눈에 파악할 수 있도록 만든 무료 정보 서비스입니다.

어떤 섹터가 강세이고 어떤 섹터가 약세인지, 최근 시장의 자금 흐름이 어디로 향하는지를 히트맵·추이 차트·랭킹 차트로 직관적으로 확인할 수 있습니다.
🇰🇷 한국 섹터 History
각 섹터는 해당 섹터를 대표하는 주요 종목들의 당일 등락률 평균값으로 계산됩니다.

색상 기준
🔴 붉은색이 진할수록 강한 상승 · 🔵 파란색이 진할수록 강한 하락 · ⬜ 흰색에 가까울수록 보합
섹터 등락률 기준: ±15% 범위에서 색상이 포화됩니다.
🕐 데이터 업데이트 주기
📡 실시간 수집 (장중 5분 간격)
· 🇰🇷 한국: KST 09:00~15:30 장중에 5분마다 수집
· 🇺🇸 미국: 미국 정규장 시간에 5분마다 수집

오늘(장중) 실시간 행
섹터 History 표 최상단에 오늘 날짜로 표시된 행은 현재 장중 실시간 등락률을 반영합니다.
⚠️ 약 20분 지연된 값이 표시됩니다.

🔧 버튼별 기술 동작 상세 주석
일반 사용자 툴팁에서 제거된 기술 상세 내용을 정리합니다.
GAS 웹앱 URL, 캐시 TTL, 영향 범위 등 개발·운영 참고용입니다.
🔄 헤더 새로고침 버튼 refreshAllData()
· 영향 범위: 웹페이지만 (구글 스프레드시트 무영향)
· 현재 보고 있는 페이지의 캐시(in-memory)를 폐기하고 GAS 웹앱에서 최신 데이터를 fetch하여 화면을 즉시 리렌더링
· 5분 자동갱신 타이머와 별개로 수동 즉시 갱신
· 구글 스프레드시트 원본의 값을 변경하거나 저장·기록하는 기능 없음
· GAS 웹앱 URL: GAS_WEBAPP_URL (스크립트 상단 상수 참조)
📡 지금 수집 버튼 — 기술 정보
· 동작: GitHub Actions fetch-realtime.yml workflow_dispatch 트리거
· 데이터 소스: 네이버 금융 API → Cloudflare KV 저장
· 쿨다운: 서버 측 5분 제한 (GAS Script Properties: TRIGGER_LAST_RUN)
· 완료 소요시간: 약 30~60초
· GAS 함수: triggerGithubActionsNoUi()
📡 한국 섹터 History — 오늘 데이터 갱신 refreshKrToday()
· 영향 범위: 웹페이지 테이블의 오늘(당일) 행만 (구글 스프레드시트 무영향)
· GAS 웹앱에서 오늘 날짜 행의 섹터 평균 등락률(약 20분 지연)을 새로 불러와 테이블 맨 위 오늘 행만 덮어씁니다.
· 과거 확정 데이터 행은 변경되지 않습니다.
· 구글 스프레드시트 원본에는 영향 없음
📡 미국 섹터 History — 오늘 데이터 갱신 refreshUsToday()
· 영향 범위: 웹페이지 테이블의 오늘(당일) 행만 (구글 스프레드시트 무영향)
· GAS 웹앱에서 오늘 날짜 행의 미국 섹터 ETF 등락률(약 20분 지연)을 새로 받아와 테이블 맨 위 오늘 행만 덮어씁니다.
· 과거 확정 데이터 행은 변경되지 않습니다.
· 구글 스프레드시트 원본에는 영향 없음
📡📅🔄 한국 섹터 종목 List — 모드 전환 / 갱신 버튼
· 오늘 실시간 버튼 setKrListMode('today'): 영향 범위 — 화면 표시 모드만 변경 (데이터 재요청·스프레드시트 무영향). 각 종목 등락률을 오늘 장중 실시간값(약 20분 지연)으로 표시. 5분마다 백그라운드 자동 갱신.
· 최근 영업일 버튼 setKrListMode('lastbiz'): 가장 최근 장 마감 후 확정·저장된 종가 기준 등락률 표시. 모드 전환만 수행.
· 갱신 버튼 refreshKrList(): 영향 범위 — 웹페이지 종목 카드 전체 (구글 스프레드시트 무영향). 섹터 구성 종목 목록과 현재 선택 모드의 등락률을 GAS 웹앱에서 즉시 다시 불러와 모든 종목 카드 갱신. 캐시(10분 TTL) 무시하고 강제 최신 데이터 수신.
📡📅🔄 미국 섹터 종목 List — 모드 전환 / 갱신 버튼
· 오늘 실시간 버튼 setUsListMode('today'): 영향 범위 — 화면 표시 모드만 변경 (데이터 재요청·스프레드시트 무영향). 각 섹터 ETF 등락률을 오늘 장중 실시간값(약 20분 지연)으로 표시. 5분마다 백그라운드 자동 갱신.
· 최근 영업일 버튼 setUsListMode('lastbiz'): 가장 최근 미국 장 마감 후 확정·저장된 종가 기준 등락률 표시. 모드 전환만 수행.
· 갱신 버튼 refreshUsListData(): 영향 범위 — 웹페이지 섹터 카드 전체 (구글 스프레드시트 무영향). 미국 섹터 ETF 목록과 현재 선택 모드의 등락률을 GAS 웹앱에서 즉시 다시 불러와 모든 섹터 카드 갱신. 캐시 무시하고 강제 최신 데이터 수신.
⏱️ 자동 갱신 타이머 구조
· 수집 주기: 5분 (GitHub Actions cron) — 장중에 5분마다 수집 후 KV 저장. 화면은 KV에서만 읽음.
· 한국/미국 데이터 확정: 장중 5분마다 GitHub Actions가 수집 → KV 저장. 장 마감 후 수집 중단 시 마지막 수집값이 확정값으로 유지됨.
· Config 시트 GAS 트리거(20:00 KST / 06:00 KST): 현재 비활성화 검토 중. GitHub Actions 마지막 수집값으로 충분히 대체 가능.
· 원 소스 (구글 스프레드시트): 히스토리 데이터의 근거. 웹 화면에서는 읽기만 수행하며 쓰기(변경/저장)는 GAS만 수행.
🔗 GAS 웹앱 연결 정보
· 상수명: GAS_WEBAPP_URL (index.html 스크립트 상단)
· 엔드포인트 형식: https://script.google.com/macros/s/[DEPLOY_ID]/exec
· 통신 방식: GET 파라미터 — ?action=kr_history 등 action 파라미터로 구분
· 응답 형식: JSON (CORS 허용 설정 필요 — GAS doGet에서 ContentService 설정)
